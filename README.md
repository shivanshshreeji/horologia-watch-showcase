# HOROLOGIA – Luxury Watch Collector and Horology Timepiece Showcase

CSE326 team project. A frontend showcase website for luxury watch collectors, with real watch photographs, a search and filter system, a shortlist, and a demo buy and checkout flow.

## Live website
https://horologia326.netlify.app

## Technologies used
- **HTML5** for the page structure
- **CSS3** for the layout, styling and the CSS-only interactions
- **JavaScript** for search, filters, shortlist, cart and the demo checkout, using localStorage
- **Netlify** for deployment
- **GitHub** for version control

## Features
- Collection storefront with watch cards
- Search and filters
- Detailed watch pages with condition and papers
- Image gallery with zoom
- Shortlist with notes
- Cart and demo checkout (no real payment)
- Works on mobile and desktop

## Files
- `index.html` – the page
- `style.css` – the styles
- `app.js` – the interactivity
- `img/` – the watch photographs

## How to run
Download the repository and open `index.html` in a browser. Keep the `img` folder next to it.

## Note
The checkout is a demo only. No payment is taken and no data leaves the browser.
